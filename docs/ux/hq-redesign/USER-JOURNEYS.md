# User journeys

| User / goal | Path | Success evidence |
| --- | --- | --- |
| Beginner: understand the team | Home → current work / attention / completed / team | Actual task/attempt/action records; unknown states labelled |
| Beginner: assign writing/research | New task → describe outcome → Start task | One returned Task assigned to Atlas; no technical configuration |
| Beginner: follow progress | Task receipt → current state / recorded milestones / related tasks | No invented stages; parent waiting distinguished from failure |
| Beginner: find result | Home completed card or Tasks → Results and files | Correct task summary and saved content open directly |
| Beginner: get help with a problem | Needs your attention → exact source | Reason, existing action, no automatic retry |
| Regular: follow employee | Team → employee → current assignments / recent work | Persistent name and portrait; task ownership and session state |
| Regular: discuss a question | Team → Conversations → choose employee → explicit reply | Conversation remains separate from Task |
| Regular: deliberate | Team → Discussions → charter → Start | Recommendation does not create work until separate assignment |
| Regular: scheduled work | Projects → Ongoing goals → schedule | Explicit approved bounds, next occurrence and retained outcomes |
| Advanced: diagnose | Task → Advanced details; Activity → Work sessions / Advanced audit | Full original identities/errors/provider evidence retained |
| Advanced: manage permissions | Settings → exact control or Team → Permissions | Existing trusted policy/approval enforcement |
| Investment: understand operation | Projects → Investment → portfolio / decisions / orders / valuation / schedule | Observed paper, research, formal decision and future work remain distinguishable |

Validation uses these paths at desktop/mobile widths and in loading/error states. Structured heuristic review is not a human participant study.
