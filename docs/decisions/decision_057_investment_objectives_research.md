# Decision 057 — Investment objectives, bounded research and cash review

Date: 2026-10-17. Status: accepted for source implementation; deployment and genuine
acceptance are separate. Supersedes the three-bar evidence projection only for
explicitly new `investment-process-v1` scopes. Decisions 029, 047 and historical
recovery authorities remain intact.

## Verified problem

At main `17729d2`, observed research requested ten calendar days and exported only
the latest three daily bars. The discussion used `allow_research:false` and zero
research calls. Merely enabling that flag would still leave private-paper policy,
worker grants, runtime tools and broker budgeting closed. The Financial Data
Gateway defines fundamentals/statements, but the approved observed direct Python
transport implements exact chart requests only. No endpoint expansion is inferred.

## Decision

Use the existing Investment run preview, exact consent, independent finite journal,
working group and server-side session schedule. A process policy records a prospective
objective, optional aspirational decimal percentage, SPY/cash evaluation period,
30–180 calendar days of daily history, exact primary sources, request limits and an
all-cash review threshold (proposed default three). Existing risk/position rules,
benchmark identity, universe, simulator method and employees are frozen in a book;
changing them requires a separately reviewed book. Evaluation cannot exceed its
frozen calendar horizon. Revisions retain old scope policy and decision history.

`processVersion` explicitly adds three tools to the frozen finite envelope without
changing legacy tool identity: paginated evidence reads, passive missing-evidence
requests and a strategy-review record. Chart acquisition stays in the gateway.
Company/regulator static pages use the existing SSRF-protected public reader with
exact session/source hashes, finite reservations, before-DNS/wire/commit authority
checks, no redirects or credentials, bounded text and no automatic retry. No search
broker, native browser, worker networking, paid feed or new model allowance is enabled.
The US$0 incremental market-data budget remains binding.

Source identity/quality and permission are explicit owner-reviewed assertions,
not a legal guarantee or a model inference. Evidence retains source metadata, hashes,
retrieval times, unknown publication/fiscal availability, missingness and truncation.
Research prices never qualify as simulator quotes. Whole relevant records must be
read in the current execution before citation, using existing 48,000-character and
16-tool-call limits. Worker context bounds accumulated request/review summaries;
full records remain private owner history.

Every new decision compares cash with the strongest permitted alternative, uncertainty,
missing evidence, an invalidation condition and a next action. HOLD distinguishes
retaining holdings, deliberate all cash and blocked research/execution. Independent
review and submission must refer to the current session. Eligibility requires a
completed occurrence and complete settled usage for producer, reviewer and submitter.
Dates, not messages or attempts, are counted; blocked sessions do not increment the
streak. Legacy decisions are not reclassified. A reviewed investment decision resets
the streak. At each threshold multiple, a due strategy review blocks the next proposal
until a concrete investigation is recorded in an existing authorized turn. If there is
no such turn, HQ asks for a bounded future review session. It never buys, loosens risk,
or allocates resources automatically. Failed review attempts remain immutable and
may be superseded by a fresh authorized attempt only after known settlement; unknown
outcomes remain fenced. Missing requests persist across scopes; an eligible reviewed
decision may explicitly address request IDs with current cited evidence.

Evaluation reports first/last common complete portfolio/SPY closing marks within the
requested period, a zero-interest USD cash baseline, costs, closing drawdown, sampled
exposure/time in cash, and missing/unmatched dates. Existing benchmark amendments,
failed attempts and original valuations remain visible. Different start dates and
methods are disclosed; no full-period SPY claim is synthesized.

New primary-source rights cover private retention/processing. Once a process-enabled
scope is saved, further public projection and delivery for that book fail closed with
`investment_process_publication_review_required`, including old standing grants.
Already published records remain retained. Public changes need a separately approved
safe derivative and coordinated canonical contract/Asymmetri handoff; no contract or
consumer deployment is made by this packet. Ask stays paused.
