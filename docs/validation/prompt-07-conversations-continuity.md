## Limits

Direct conversations only; peer answers and their bounded continuation live in the peer
transcript. No automatic human-thread synthesis, working groups or operating loop.
Memory is bounded original excerpts plus eight source bookmarks and structured obligations;
it is not perfect long-term semantic recall. Unknown provider outcomes require inspection;
there is no UI button to clear the shared uncertainty fence or a claim of exactly-once
provider invocation. Browser ownership remains administrative oversight. Device API v1
does not gain conversation authority. See [operator semantics](../architecture/CONVERSATIONS_AND_CONTINUITY.md).
