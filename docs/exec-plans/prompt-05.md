## Architecture and enforcement plan

Project owns trusted instructions, protected paths, writer/review ceilings, bounds
and named recipes; it may own several repositories. A repository owns its canonical
managed Git root, configured branch, current commit, source identity and remote policy.
Tasks bind explicit repository scope. Managers may narrow allocation authority only.

Scopes use normalized exact paths or directory prefixes, no glob semantics. Reject
overlap before provisioning and protect AGENTS/default metadata paths. Persist immutable
allocation manifest hashes in the trusted control plane and root clone ledger. Workers
never supply new scope on a write. Root handles only existing fixed infrastructure/UID
operations; remote Git is a non-root application adapter.

Recipes are human-configured named argv operations using an explicitly supported
runtime allowlist. Workers choose recipe IDs, never executable/argv/env. Run untrusted
code in disposable snapshots with no network, host/state/auth/sibling access, bounded
time/output/memory and contained writable temporary/build space. No package installation.

Each immutable submission binds allocation/base/head/range/paths/validation/execution.
Each review round binds exact submission IDs and trusted packet evidence. Changes
required requeues affected existing engineer tasks with explicit review provenance,
same worker/thread and a bounded ceiling. Earlier rounds remain inspectable.

Integration intent is persisted, serialized per repository and event-driven. Recheck
base, exact approval and canonical state; retain candidate and logs; advance only after
full validation. Completed work cannot replay. Ambiguous state blocks for inspection.

Normalize GitHub HTTPS identities, reject credentials and unsafe metadata, keep remote
credentials out of DB/worker contexts. Default remote policy is none. Fetch requires
explicit trusted action; divergence blocks. Push requires exact human approval binding
project/repository/remote/branch/expected-old/new/integration. Use a separate non-root
receipt/reconciliation path, no force or branch deletion. Mandatory local bare fixture;
authenticated live GitHub push is unvalidated unless safe disposable target and exact
human approval exist.

Archive reduces authority while preserving repositories and evidence; block unsafe
active work, release exact clone bindings without deleting homes/history. Reboot is
required if provisioner installation/protocol changes, which is expected here.
